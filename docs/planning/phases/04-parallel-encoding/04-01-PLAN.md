## Goal
Implement parallel OGG/Opus encoding during recording so post-release latency drops below 1000ms p50.

## Tasks

1. **transcribe.py** — Add `ParallelEncoder` class (queue + background thread + OGG container)
2. **transcribe.py** — Refactor `_encode_and_transcribe`: extract `_call_transcription_api(client, model, buf, timeout)`; add `_transcribe_preencoded` wrapper
3. **transcribe.py** — Update `transcribe_with_fallback` / `_try_transcribe` to accept and pass `pre_encoded: Optional[io.BytesIO]`
4. **state.py** — Add `encoder: Any = None` field to `AppState`; update `request_cancel()` to capture and return encoder for outside-lock discard
5. **audio.py** — `audio_callback`: feed chunks to `state.encoder` alongside `state.audio_chunks`
6. **audio.py** — `_start_mic_stream`: create `ParallelEncoder()` and assign to `state.encoder` after stream starts
7. **audio.py** — `stop_and_transcribe`: capture encoder from state under lock; call `encoder.flush()` with span; pass `pre_encoded` to `transcribe_with_fallback`
8. **audio.py** — `cancel_recording`: receive encoder from `request_cancel()` and call `encoder.discard()`

## Success Criteria
- PERF-02: p50 end-to-end < 1000ms, p95 < 1500ms for 4–25s dictations
- Cancellation discards encoder without blocking
- Retry path unchanged (uses raw state.audio_chunks)
- Encoder queue bounded at 60s max

## Risks
- PyAV frame pts tracking: must be monotonically increasing; implement sample-accurate counter
- Queue.put_nowait in audio_callback is safe (no blocking) but drops chunks if queue is full at 60s
- Flush timeout (5s): if exceeded, fall back to re-encoding raw audio
